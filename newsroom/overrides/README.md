# Optional human overrides

Drop a markdown file here if you want the desk to take a note on the next run.

The desk runs without this folder having any instructions. Files here are optional.

Examples:

- `pause-publication.md` — “HOLD is in effect until I remove it.”
- `prefer-beat.md` — “If you start a new lead today, prefer EU Official Journal over SEC.”
- `do-not-name.md` — “Do not name X until we have the second filing.”

Overrides cannot authorize invented quotes, fake bylines, or news articles as primary proof.
